# Contribuir

Registrar fuente, revisión PCB, orientación, fecha, instrumento y condiciones para
cada medida. No sustituir TBD por estimaciones. Una asociación de conector no es un pinout.
Cambios de control requieren pruebas de fallo; cambios eléctricos, revisión independiente.
No incorporar manuales ni firmware de terceros sin permiso de redistribución.
Ejecutar las comprobaciones del README y explicar limitaciones de los resultados.
